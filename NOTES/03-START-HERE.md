## Запустить локально

```bash
node tools/serve.mjs     # http://localhost:4173
```

Данные пересобирать не нужно — они в репозитории. Если понадобится обновить каталог
с живого сайта: `npm run data` (нужен `npm install` — фото пережимает `sharp`). Фото
товаров лежат в `assets/products/` и докачиваются только новые или изменившиеся.
Карту (OpenStreetMap) — `npm run map`, но она ограничена одним запросом в секунду,
трогать без нужды не стоит.

## Что надо знать, прежде чем что-то менять

Три вещи, на которых всё держится — они подробно описаны в `01-ARCHITECTURE.md`:

1. **Слои тортов не выдуманы.** Они разобраны из описаний товаров цеха. Правки состава —
   в `tools/lexicon.mjs` и `tools/build-data.mjs`, не в рендерерах.
2. **`\w` и `\b` в JavaScript не работают с кириллицей.** Любой новый шаблон в лексиконе
   обязан проходить через хелпер `cyr()`, иначе молча не найдёт ничего.
3. **`assemble()` в `js/recipe.js` повторяет `buildStack()` в `tools/build-data.mjs`.**
   Меняешь правила сборки — меняй в обоих местах, иначе торт из конструктора перестанет
   совпадать с тортом из каталога.

И ещё: **никогда не делай видимость элемента зависящей от анимации**. Один раз уже
обожглись — слои разреза оставались невидимыми, когда анимация не запускалась.

## Что осталось незакрытым

- **Цена в конструкторе — оценка**, диапазон по похожим тортам. Настоящий прайс на заказные
  торты у цеха не публичный.
- **Два правила доставки на сайте цеха противоречат друг другу** («бесплатно от 1000 ₽» и
  «от 2000 ₽ без указания времени»). Показываю оба как есть. Стоит уточнить у клиента.
- **Пин на карте открывает не свой район.** Клик по пину выбирает первый район с той же
  зоной цены, а не тот, где место на самом деле: «Затон» открывает «Дёмский район».
  Нужна привязка микрорайона к району в `data/ufa.json`.

- **Розочки, ягоды и надпись в цене не учтены.** Приложение честно пишет «без учёта
  украшения и надписи» — прайса на оформление у цеха нет. Если клиент даст цены,
  их место в `orderText()` и итоге в `js/page-app.js`.
- **`sw.js` кэширует приложение для работы без сети.** Код и данные идут сначала из сети,
  так что деплой подхватывается при следующем открытии. Если поменяется список файлов
  приложения — обнови `SHELL` в `sw.js` и подними версию `CACHE`.

## Идеи, до которых руки не дошли

1. `og:image` на каждый торт, отрисованный из разреза — самое расшариваемое, что тут есть,
   а превью у него сейчас нет.
2. Настоящее оформление заказа. Сейчас корзина отдаёт заказ в WhatsApp.
3. Фотография реального разреза рядом со схемой — доказательство, что схема честная.
4. Обновлять `data/` по расписанию, чтобы цены не расходились с каталогом.
